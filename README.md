# ePlaneur

Symfony 8.1 application (PHP 8.5, MariaDB 11.8, AssetMapper + Stimulus/Turbo), fully dockerized.

```bash
make install   # first setup, see doc/installation.md for the prerequisites
make           # list every command
```

- Site: https://eplaneur.local — Mailpit: http://localhost:8025
- Documentation: [doc/](doc/README.md)
