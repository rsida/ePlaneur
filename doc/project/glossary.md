# Glossary

French terms are kept as they appear on the site (user-facing content stays in French).

| Term | Meaning |
|---|---|
| **ePlaneur** | Virtual gliding with a simulator, name adopted by the FFVP on 26 Oct 2022 (previously "eSport"). Also the name of the project and of eplaneur.fr |
| **ePilote** | A virtual glider pilot following a structured training (as opposed to a *gamer*). Also the internal qualification obtained at step 3 |
| **Élève ePilote / ePilote Solo / ePilote breveté Condor Club** | Internal qualifications of steps 1, 2 and 4 |
| **Gaming** | Flying without method, for fun only; tolerated as a break, discouraged as a learning mode |
| **FFVP** | Fédération Française de Vol en Planeur, French gliding federation |
| **BIA** | Brevet d'Initiation Aéronautique, French school aeronautics certificate; BIA teachers and students are a key audience |
| **SPL** | Sailplane Pilot Licence (real glider licence) |
| **CD** | Comité Directeur, the club's governing committee |
| **Condor 2 / Condor 3 (C2 / C3)** | Versions of the Condor Soaring Simulator; C2 for initiation, C3 from step 7 and for competition |
| **Scène** (scenery) | Geographic area flown in Condor (AA2/AA3 = Arc Alpin, FrSW, Slovenia...) |
| **Hangar** | Set of gliders available in Condor, versioned; must match the server |
| **FPL** | Flight plan file (`.fpl`) defining task, weather, glider, start type. Codified in the eplaneur.fr database, e.g. `C2-d015` |
| **Fiche FPL** | One-page sheet describing an FPL, with VAC landing chart and tips |
| **Circuit CC** | A task published on the Condor Club, used to record and compare performances |
| **Condor Club (CC)** | Community site: CN reservation, sceneries, online logbook, circuits, badges, competitions |
| **CN** | Competition Number identifying a pilot in Condor; recommended as username on the club site |
| **FTR** | Condor flight trace file, uploaded to a Condor Club circuit |
| **Logbook (carnet de vols)** | Local `logbook.txt` (not reliable) vs Condor Club online logbook (reference) |
| **Vol en réseau** | Network (multiplayer) flight on a Condor server |
| **Stop Join** | Time window during which pilots can join or rejoin a network session |
| **Départ régate** | Regatta start: all gliders start together when the gate opens |
| **Ballast** | Water ballast; limited, overweight is penalised |
| **Local** | Staying within gliding range of an airfield or landable field |
| **Champ vachable** | Landable field |
| **DDH** | Height margin above the required arrival height |
| **Vi / VNE / TAS** | Indicated airspeed / never-exceed speed / true airspeed |
| **Mac Cready** | Speed-to-fly theory used to optimise inter-thermal speed (step 5) |
| **XCSoar / LX** | Flight computers usable with Condor (XCSoar external, LX built into Condor 3 with XC option) |
| **Insigne Argent** | Condor Club Silver badge: 1 h flight, 1,000 m gain, 50 km distance |
| **Brevet ePlaneur** | Federal certificate project proposed by the club; does not exist yet |
| **Yapla** | Membership and payment platform used by the club |
| **Pause estivale** | Summer reduced-activity period (about May to mid-October) |
| **Mitch** | Nickname of the club administrator / head of the ePlaneur commission, who manages the flight server and eplaneur.fr |
